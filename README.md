# Termote plugins

The termote plugin for Claude Code and Codex: a skill that coordinates the coding agents running
in your [termote](https://termote.ohnice.app) panes from one session.

This repository is generated from [lamngockhuong/termote](https://github.com/lamngockhuong/termote)
at each stable release; do not edit it here. The plugin arrives with the first release that has
`termote agents`.
